# Portfolio Design Skill

## Purpose
Maintain aesthetic consistency, editorial typography, dark-first color palette, and clear visual hierarchy reflecting a backend engineering / incident room concept.

## Principles
- **Incident Room Aesthetic**: Technical control room feel, dark slate background (`#0E1620`), crisp borders (`#2A3A4D`), amber accents (`#F5A524`), health indicator green (`#3DD68C`), and error red (`#FF5D5D`).
- **Typography**: Display in Bricolage Grotesque, Body in Hanken Grotesk, Technical/Code in JetBrains Mono.
- **Hierarchy & Layout**: 12-column grid desktop, 4-column mobile. Max width ~1200px. Content must remain readable and structured without animation.
- **Dual Themes**: Dark theme first with seamless light theme support via CSS variables.
- **Privacy & Respect**: Never display personal private data (DOB, home address, personal phone numbers, client proprietary data).
