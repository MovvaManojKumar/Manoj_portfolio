# Workflow: Portfolio Plan & Audit

## Objective
Audit the workspace, cross-verify resume and professional records, establish design constraints, and present an implementation plan before writing any code.

## Steps
1. Inspect directory structure, existing dependencies, and package files.
2. Cross-reference source facts (resume, Naukri, specifications).
3. Generate `docs/PROJECT_AUDIT.md`, `docs/CONTENT_VERIFICATION.md`, and `docs/IMPLEMENTATION_PLAN.md`.
4. Halt for user review and approval before proceeding to implementation.
