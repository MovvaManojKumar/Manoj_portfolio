# Workflow: Portfolio Motion Review

## Objective
Implement Motion for React components, wire up signature animations (Incident Trace, Request Journey, 3D Tilt), and benchmark performance.

## Steps
1. Install `motion`.
2. Construct reusable primitives: `Reveal`, `StaggerContainer`, `MagneticButton`, `TiltCard`, `SpotlightCard`.
3. Implement Hero Trace with skippable controls and reduced-motion instant resolution.
4. Animate Request Journey architecture diagram.
5. Verify on touch devices and test reduced-motion toggling.
