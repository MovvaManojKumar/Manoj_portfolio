# Workflow: Portfolio Build Phase

## Objective
Scaffold the React + Vite + TypeScript application, set up design tokens and themes, and construct static content sections.

## Steps
1. Initialize clean React + TypeScript + Vite project structure.
2. Establish CSS token system (colors, spacing, typography, radii, shadows) in `src/styles/tokens.css` and `src/styles/themes.css`.
3. Build modular data layer (`src/data/`) separating content from components.
4. Construct Navigation, Hero, About, Experience, Skills, Projects, Learning, Education, Contact, and Footer with static accessibility.
5. Verify build integrity (`npm run build`).
